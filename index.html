Technical API Reference

بروتوكول تفعيل تنبيه شاشة القفل التفاعلية

طريقة الربط وآلية تدفق البيانات

بمجرد استشعار البنك لخطورة معينة، يرسل خادم البنك طلب POST مشفر يحتوي على معطيات العملية إلى سيرفر "رادع" لتنبيه تطبيق العميل على شاشة القفل فوراً دون أي تأخير شبكي.

المعطيات المطلوبة (Payload Properties):

  • user_id: المعرف الفريد للعميل المستهدف.
  • fraud_score: نسبة احتمالية التزوير المحتسبة من خوارزميات البنك.
  • transaction_amount: قيمة العملية المشبوهة لإبرازها على شاشة القفل.
import requests payload = { "user_id": "usr_sanad_2026", "fraud_score": 0.94, "transaction_amount": "4,500 SAR", "action_trigger": "lockscreen_interactive_popup" } response = requests.post("https://api.radae.internal/v1/alert", json=payload) print(response.status_code)
